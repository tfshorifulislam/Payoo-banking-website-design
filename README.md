# Payoo Banking Website Design

**Payoo Banking Website Design** is a modern and responsive banking website UI built to demonstrate clean layout design and a user-friendly interface for a digital banking experience.

## 🌟 Features
• Clean and modern banking website layout  
• Responsive design for mobile, tablet, and desktop  
• User-friendly interface for better user experience  
• Structured and organized UI components  
• Smooth and simple navigation  

## 💻 Technology Stack
• HTML5  
• CSS3  
• Tailwind CSS
